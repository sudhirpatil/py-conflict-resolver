Automatic conflict resolution exhausted all attempts without finding a fully compatible set of versions. As a last resort, the agent split your packages into two groups: compatible packages (installed normally) and conflicting packages (force-installed with --no-deps, bypassing the resolver).

Use with caution — the environment may fail at runtime if force-installed packages have incompatible runtime requirements. Review the pip check output and test thoroughly.
